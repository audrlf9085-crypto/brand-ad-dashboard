# 4개 브랜드 광고 대시보드

플랜튜드 · 아이비에듀 · 초당약품 · 모어댄트립의 메타 광고, 인스타그램 콘텐츠, 팔로워를 한 화면에서 비교하는 대시보드입니다.

## 파일 구성
- `index.html`: 대시보드 화면
- `d3.v7.min.js`: 차트를 그리는 라이브러리 (수정하지 마세요)
- `data/meta_ads.csv`: 메타 광고 캠페인별 집행 내역
- `data/ig_content.csv`: 인스타그램 콘텐츠별 성과
- `data/ig_followers.csv`: 인스타그램 일별 팔로워

## 숫자 업데이트하는 법
`data/` 폴더의 CSV 파일만 같은 이름의 새 파일로 바꿔 올리면 됩니다. 1~2분 뒤 페이지에 반영돼요.
